# Pal Donation Bridge

치지직 채팅·후원 이벤트를 팰월드 일반 멀티플레이 초대방의 방장 캐릭터에게 연결하는 Windows 데스크톱 애플리케이션입니다.

## 현재 구현 범위

- 치지직 OAuth 인증
- Socket.IO v2 세션 연결
- 일반 채팅과 후원 이벤트 수신
- Electron 데스크톱 UI
- 사용자에게 Client ID·Secret·리디렉션 URL을 요구하지 않는 간편 로그인
- Cloudflare Worker Secret 저장소를 이용한 OAuth 토큰 교환
- AES-GCM 암호화 및 1회 수령 후 삭제되는 인증 티켓
- 운영체제 보안 저장소를 이용한 사용자 토큰 암호화
- 기존 개인 모드와 대표 PC 기반 파티 방장 모드 선택
- 친구 방송인의 웹 로그인·팰월드 캐릭터 연결
- 대표 PC에서 여러 치지직 방송을 동시에 수신하는 무료 로컬 중앙 서버
- 친구 토큰의 일회용 AES-GCM 전달, 로컬 암호화 저장 및 자동 갱신
- 팰월드 접속자 이름별 원격 후원 효과 실행
- Steam에 설치된 팰월드 자동 탐색
- SHA-256 검증 후 팰월드 1.0용 UE4SS와 방장용 모드 자동 설치
- IP·포트포워딩 없이 팰월드의 일반 초대 코드 사용
- 방장 PC 내부 명령 파일을 이용한 앱↔게임 통신
- 1천·3천·5천·8천·1만·5만원 후원의 지급·회복·방해·사망 효과
- GitHub Actions를 이용한 Windows `Setup.exe` 자동 빌드

> 일반 초대방 모드는 Windows 실전 검증 단계입니다. 앱을 업데이트하면 방장 모드도 다시 설치하고 팰월드를 완전히 재실행한 뒤 각 테스트 버튼을 먼저 확인하세요. 구버전 모드가 실행 중이면 대상 없는 효과가 방장에게 적용될 수 있어 앱에서 실행을 차단합니다.

## 실행 모드

- `개인 모드`: 기존 방식입니다. 방송인 각자가 앱을 설치하고 자기 치지직 방송을 연결합니다.
- `파티 방장 모드`: 대표 방송인만 앱을 실행하고 참여 링크를 공유합니다. 친구 방송인은 웹에서 치지직 로그인과 팰월드 캐릭터 이름 연결만 진행합니다.

파티 후원 수신 서버는 대표 PC에서 실행되므로 별도 유료 서버나 포트포워딩이 필요하지 않습니다. 대표 앱이 종료되면 파티 후원 수신도 함께 종료됩니다. 파티 방송 전에는 접속자 목록과 각 방송인의 `고기 테스트`로 대상 캐릭터가 정확한지 확인하세요.

파티 운영 순서는 다음과 같습니다.

1. 대표 PC에서 `파티 방장 모드`를 선택하고 방장 모드를 설치합니다.
2. 팰월드 멀티플레이 월드에 모두 입장한 뒤 `파티 시작`을 누릅니다.
3. 표시된 참여 링크를 대표 방송인을 포함한 방송인들에게 보냅니다.
4. 각 방송인은 링크에서 자기 팰월드 캐릭터명을 정확히 입력하고 자기 치지직 계정으로 로그인합니다.
5. 대표 PC에서 접속자 이름과 연결된 방송인 이름이 일치하는지 확인하고 `고기 테스트`를 한 번씩 실행합니다.

문제가 생기면 앱에서 `개인 모드`를 선택해 기존 방식으로 즉시 돌아갈 수 있습니다. 기존 `v1.3.0` 설치 파일도 릴리스에 그대로 보존됩니다.

## 개발 실행

```bash
npm install
npm run desktop:dev
```

CLI 수신기는 다음으로 실행합니다.

```bash
npm run dev
```

## 빌드

```bash
npm run build
npm run package
```

Windows 설치 파일은 GitHub Actions의 `Build Windows installer` 워크플로를 수동 실행하면 생성됩니다.

## 인증 서비스

최종 사용자는 치지직 인증 정보를 입력하지 않습니다. `worker/`의 Cloudflare Worker가 Client Secret을 암호화된 Secret으로 보관하고 OAuth 토큰 교환을 대행합니다. 운영자의 최초 배포 절차는 [docs/OPERATOR_SETUP.md](docs/OPERATOR_SETUP.md)를 참고하세요.

## 보안

- `.env`는 Git에 포함되지 않습니다.
- Client Secret, Access Token, Refresh Token을 이슈·로그·커밋에 올리지 마세요.
- 게임 명령은 외부 네트워크 포트를 열지 않고 방장 PC 내부의 명령 파일로만 전달합니다.
- UE4SS는 앱에 재배포하지 않고 팰월드용 원본 GitHub 릴리스에서 실행 시 내려받아 SHA-256으로 검증합니다.
- 기존 UE4SS가 발견되면 사용자 파일을 덮어쓰지 않고 설치를 중단합니다.
